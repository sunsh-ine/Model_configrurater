# N5 易用性验收测试包（总览）

**目的**：验证一个**不熟悉本项目源码**的人，只凭 README 与示例配置，能否完成
"改需求 → 跑评估 → 读懂结论 → 知道下一步还缺什么"。

> ⚠️ 这项验收**必须由真人**完成。Agent 已经知道答案，自己跑脚本**不算**通过。

## 材料（已按"参与者 / 评分者"分开存放）

| 文件 | 给谁 | 内容 |
|---|---|---|
| [`n5_participant_tasks.md`](n5_participant_tasks.md) | **参与者** | 环境准备、6 个任务、空白反馈表。**不含**预期答案 |
| [`n5_grader_guide.md`](n5_grader_guide.md) | **评分者** | 预期答案、判定标准、记录要求。**不要给参与者看** |
| [`n5_usability_validation.md`](n5_usability_validation.md) | 记录 | 验收结果（当前状态：**未开展**，不预填结论） |

## 流程

1. 评分者先把 `n5_participant_tasks.md` 单独发给参与者（或让其只读这一份）；
2. 参与者完成 6 个任务并交回反馈表；
3. 评分者按 `n5_grader_guide.md` 判卷，把原始反馈与判定写入
   `n5_usability_validation.md`；
4. 只修**真实发现**的使用障碍；在有人实际卡住之前不开发 Web 前端。

## 通过条件

* **通过**：任务 3、4、5 全部正确，且无需询问即可完成任务 2；
* **有条件通过**：任务 4 或 5 有误解，但错误集中在措辞而非结论；
* **不通过**：把模拟预测当成实测、把假设成本当成报价、或找不到下一步建议。

> 特别提示（评分者）：默认 Demo **没有**开启模拟、也**没有**目标配置的真实实测。
> 因此参与者回答"模拟预测不存在""真实实测不存在"是**正确**的。
