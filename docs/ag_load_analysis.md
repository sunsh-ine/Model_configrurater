# AG3 有限窗口负载与队列分析

> 逐请求数据来自 AISimulate `--capture-per-request`；缺失队列字段保持 unknown，不默认 0。

## 指标来源

| 指标 | 字段/算法 | 口径 | 状态 |
|---|---|---|---|
| TTFT | `ttft_ms` | 请求到首 token（工具逐请求字段） | available |
| TPOT | `(last_token_ms - first_token_ms)/(output_length-1)` | 逐请求推导；不是 ITL 池 | derived |
| E2E | `e2e_latency_ms` | 请求到末 token | available |
| 路由 queue_wait | `routing_history[].queue_wait_ms` | 路由层等待，不等于模型 scheduler queue time | available_per_request |
| 模型 scheduler 等待 | `—` | 工具未提供 | unknown |
| 队列长度/等待请求数时间序列 | `—` | 工具未提供全局队列采样 | unknown |

## 结论边界

- 路由 `queue_wait` 有逐请求来源；模型 scheduler 等待与全局队列长度不可用；
- 前半/后半与首尾 100 请求只用于观察窗口内变化，不是显著性检验；
- 不据此声明长期稳定容量或最大稳定 RPS。
