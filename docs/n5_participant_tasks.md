# N5 参与者任务单

> 这份文件**只给参与者**。请不要阅读 `docs/` 下的其它文档（尤其是 `n5_grader_guide.md`）。

## 你要做的事

在**不看源码**的前提下，用下面这份材料完成 6 个任务，并填写最后的反馈表。
遇到卡住就记下来，**不要问出题人"应该是什么"** —— 卡点本身就是我们要的信息。

计时从你打开终端开始。

## 环境准备

```bash
git clone https://github.com/sunsh-ine/Model_configrurater.git
cd Model_configrurater

python3 -m venv .venv
.venv/bin/pip install -r requirements.lock
bash scripts/run_demo.sh /tmp/n5-demo      # 无 GPU、无网络即可
```

预期：命令最后打印 `报告: /tmp/n5-demo/demo_report.md`，该文件与
`demo_result.json` 都已生成。

## 任务

| # | 任务 |
|---|---|
| 1 | 打开 `data/examples/demo_qwen3_32b_h100.yaml`，把**并发**改成 64、把 **TTFT P99 阈值**改成 200ms |
| 2 | 重新生成报告（命令在 `README.md` 里，自己找） |
| 3 | 回答：系统给出的**资源可行**部署配置是哪几个？哪几个静态不可行？ |
| 4 | 在报告里指出下面四类数字**当前是否存在**：① 公开实测参考 ② 模拟预测 ③ 假设成本 ④ 目标配置的真实实测。**某一类不存在就直接写"不存在"** |
| 5 | 回答：报告为什么说 SLA"证据不足"？若要拿到达标结论，下一步要做什么？ |
| 6 | （可选）用 `data/examples/scenario_simulation_auto.example.yaml` 跑一次模拟选型；若没装工具，报告怎么说明？ |
