# AI5 实测与模拟预测边界

基线：`fd539e6`

## 1. AISimulate 对 RTX 3090 的支持

检查本机 AISimulate 0.12.1 的 systems 目录，现有硬件为：

`a100_pcie`、`a100_sxm`、`a30`、`b200_sxm`、`b300_sxm`、`b60`、
`gb200`、`gb300`、`h100_pcie`、`h100_sxm`、`h200_sxm`、`l4`、`l40s`、
`rtx_pro_6000_server`。

**没有 `rtx3090` / RTX 3090。** 因此本阶段按 AI5 情况 B 处理：

* 不修改模拟器内部硬件数据伪装支持；
* 不用 H100/H200 预测替代 3090；
* RTX 3090 实测作为独立真实 Benchmark 证据；
* 3090 的预测校准状态保持 `unknown`。

## 2. 校准状态

| 项 | 状态 |
|---|---|
| 3090 同工作点模拟预测 | 不存在 |
| 真实预测误差 | 不能计算 |
| 全局修正系数 | 不训练 |
| 跨 GPU 复用 P99 | 禁止 |
| 实测入库 | 见 `ai_rtx3090_results.md` |

## 3. 允许的比较

只有在模型、硬件、框架、精度、并行度、ISL/OSL、到达方式和并发/到达率
全部一致时才能比较预测与实测。当前缺少 3090 模拟侧，条件不成立。

3090 实测可以帮助验证导入链路、SLA 判定和数据治理，但不能证明
H100/H200 模拟预测的准确度。
