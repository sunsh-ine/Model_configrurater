# X5：Agent 模式受控部署方案（仅设计，未实施）

本文件描述将来把 Agent 模式部署到共享环境所需的最小控制面。
**当前未向 `compute01` 加入 Command Code 登录态，也未开放公网入口。**

## 目标与非目标

目标：

1. 用户只能通过受认证的入口提交自然语言需求；
2. 模型凭据只在服务端，不下发浏览器；
3. 每个任务有独立工作目录、超时和并发上限；
4. 报告仍只来自 `evaluate_plan()`，Agent 文本不进入结论；
5. 出现异常可停止接入并回滚到手动模式。

非目标：多用户协作、复杂配额计费、多 Agent 编排、公网匿名访问。

## 建议架构

```
[内网用户]
   │ HTTPS + SSO/网关鉴权
   ▼
[Streamlit 手动模式]  [Agent 入口（同一页面，需登录）]
                              │ 内部 token / mTLS
                              ▼
                    [Agent 编排服务（独立进程/容器）]
                    ├─ 任务队列 + 并发/超时/配额
                    ├─ Command Code + 每任务 bwrap 沙箱
                    ├─ MCP server（三个业务工具）
                    └─ 任务/报告目录（按用户/任务隔离）
                              │
                              ▼
                    [现有计算引擎 + 报告]
```

## 控制项

| 项 | 方案 |
| --- | --- |
| 入口认证 | 网关 SSO 或反向代理鉴权；未认证请求不得进入 Agent 路由 |
| 服务间认证 | 内部 token 或 mTLS；Agent 服务不直接暴露公网 |
| 模型凭据 | 由 secret manager / 受控环境注入；不写前端、不入 Git、不进报告 |
| 每任务隔离 | 独立 bwrap 沙箱与 HOME；只挂载必要代码/数据/任务目录 |
| 并发 | 全局与每用户上限；超出排队或拒绝，返回明确状态 |
| 超时 | 模型调用、工具调用、总任务各有上限；超时不生成报告 |
| 配额 | 每日/每次任务的调用次数与 token 预算；可审计 |
| 日志 | 不记录密钥；提示词/报告按需脱敏与保留期；任务 ID 可追踪 |
| 数据访问 | 只读代码与公开数据；禁止 `data/private`、`local.db`、raw xlsx |
| 任务/报告 | 每任务唯一目录；`task_id/run_id/hash` 绑定；防止跨用户读取 |
| 失败处理 | Agent 失败时保留手动模式；不采用模型文本生成报告 |
| 回滚 | 镜像/配置版本化；关闭 Agent 路由即可回到手动模式 |

## 部署前置检查

- [ ] 入口有认证，Agent 路由未认证不可达
- [ ] 模型凭据在服务端，未出现在浏览器/日志/仓库
- [ ] bwrap 或容器边界在目标主机可用
- [ ] 沙箱不包含内部定价数据与真实 HOME
- [ ] 并发/超时/配额已配置并有测试
- [ ] 任务与报告目录按用户隔离
- [ ] 有回滚开关与演练记录
- [ ] 安全评审与部署批准
