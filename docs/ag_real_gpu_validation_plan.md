> 5 次独立 Benchmark 时间预算。AG5 不阻塞 AG0–AG4、AG6–AG8 的离线验收。

## 1. 前置条件

与 `docs/af_real_gpu_validation.md` 相同，并额外要求：

* 每个工作点至少 5 次独立 Benchmark（不同启动或不同 seed），预热窗口单列；
* 原始逐请求日志、服务端启动参数、驱动/CUDA、模型 revision、权重精度全部归档；
* 原始文件 SHA256、操作人、开始/结束时间写入实验清单；
* 使用 `perf/benchmark_ingest.py` 的冻结身份与导入校验；
* 不占用生产流量，不影响现有服务。

## 2. 首批实验

| 实验 | 部署 | 核心问题 |
|---|---|---|
| G1 | 8B/H100 TP1×DP1、TP1×DP2 | DP 副本实际带来多大 SLA 改善 |
| G2 | 8B/H100 DP2，C40/C48/C56 | 模拟容量边界与实测是否一致 |
| G3 | 8B/H100 DP2，Poisson 4/5 req/s | 开放到达尾延迟与排队是否符合预测 |
| G4 | 32B/H100 TP8×DP1、TP4×DP2 | 同 8 卡时模拟推荐排序是否成立 |

H200 作为第二批，不在首轮同时覆盖。

## 3. 验收

* 5 次运行全部有有效 P99 与完整哈希，才形成 `complete` 重复性实验；
* 预测/实测误差只在身份完全匹配时计算，且原始日志可重算；
* 模拟不确定度与实测误差分开报告；
* 任一条件缺失时保持 `unknown`，不能用其他 GPU 结果替代。
