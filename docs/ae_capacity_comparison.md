# AE2/AE3：容量对比与到达率实验

基线：`b4dd888`

> 全部为 AISimulate 预测；固定并发与 Poisson 分开，不合并排名。

## 2. Poisson 到达率实验

配置：ISL8192 / OSL256、500 请求、seed 42、6000/40。到达率与固定并发
不是同一工作点，不能交叉复用 P99。

### Qwen3-8B / H100 / TP1×DP1

| 到达率 req/s | TTFT P99 | TPOT P99 | 结论 |
|---|---|---|---|
| 1 | 654.55 | 18.04 | pass |
| 2 | 1004.05 | 53.25 | fail（TPOT） |
| 3 | 23321.41 | 64.00 | fail |
| 4 | 60174.81 | 76.13 | fail |

### Qwen3-8B / H100 / TP1×DP2

| 到达率 req/s | TTFT P99 | TPOT P99 | 结论 |
|---|---|---|---|
| 2 | 452.28 | 14.66 | pass |
| 3 | 582.19 | 23.55 | pass |
| 4 | 670.68 | 34.59 | pass |
| 5 | 876.81 | 55.32 | fail（TPOT） |

**已验证通过的最高到达率：4 req/s。** 5 req/s 未通过；5 以上没有验证。

### Qwen3-8B / H200 / TP1×DP2

| 到达率 req/s | TTFT P99 | TPOT P99 | 结论 |
|---|---|---|---|
| 2 | 435.37 | 10.99 | pass |
| 3 | 554.44 | 16.48 | pass |
| 4 | 625.42 | 26.29 | pass |
| 5 | 762.86 | 36.36 | pass |

**已验证通过的最高到达率：5 req/s**（本批只测到 5，不能表述为稳定上限）。

### 种子稳定性

8B/H100 TP1×DP2、3 req/s：

* seed 42：TTFT 582.19 ms、TPOT 23.55 ms；
* seed 7：TTFT 593.52 ms、TPOT 20.91 ms。

两次都通过；TTFT 差异约 1.9%，TPOT 差异约 11.2%。这是**有限窗口的随机波动**，
不是实测误差校准。

## 3. 结论边界

* 固定并发只说明“闭环在途上限”下的预测；
* Poisson 只说明“500 请求有限窗口、指定 seed”的预测；
* 实际完成 RPS 可能低于配置到达率（例如 3 req/s 的完成约 3.18），
  不能把配置值当成服务能力；
* 未验证区间保持 unknown，不做 P99 插值；
* 最高已验证并发/到达率不是生产容量保证。
